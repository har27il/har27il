### `03` — Featured Project: Minions

**Job Intelligence Pipeline** — Live production automation
*Processing 3,300+ jobs daily | 99%+ uptime | 95% manual overhead reduction*

**Problem:** Manual job posting aggregation across HR platforms (Greenhouse, Reed, Lever) created operational bottlenecks.

**Solution:**
- Automated data ingestion from multiple HR APIs
- LLM-powered job classification with structured JSON outputs
- Notion database sync and automated report generation
- Production-grade error handling and retry logic

```bash
# Example: Fetch and classify jobs
python minions/pipeline.py --source greenhouse --output notion
```
